ChatGPT：プロジェクト

同じテーマの会話・資料・共通の指示をまとめ、継続して作業する機能です。プロジェクト内で新しいチャットを始めると、登録した資料や共通の指示を使って相談できます。

プロジェクトで試す

  1. プロジェクトを作り、名前を付ける。
  2. プロジェクトの指示に共通の設定を入れ、ソースに業務資料を追加する。
  3. そのプロジェクト内で新しいチャットを始め、質問する。

公式情報：ChatGPT：プロジェクト

Claude：プロジェクト

同じテーマの会話・資料・共通の指示をまとめ、継続して作業する機能です。

以下は従来版のプロジェクトの手順です。一部のPro／Max／Ultra利用者には新しいプロジェクトのベータ版が段階的に提供され、既存プロジェクトの移行も始まっています。移行済みの画面では操作が異なる場合があります。

  1. プロジェクトを作り、名前を付ける。
  2. プロジェクトの指示に、役割・回答形式・注意点を保存する。
  3. 知識に資料を追加し、プロジェクト内で質問する。

Freeは最大5件のプロジェクト。有償プランは大量の知識をRAGで扱えます。Team／Enterpriseでは組織内で共有できます。

公式情報：Claude：プロジェクト

Gemini Notebook：資料を中心に試す

  1. Geminiの「ノートブック → 新しいノートブック」で名前を付ける。
  2. 「ソースを追加」から業務資料を入れる。
  3. ノートブックの設定に共通の指示を入れ、ノートブック内で質問する。

資料・カスタム指示・会話をまとめて扱う方法です。Geminiとの連携は順次提供。Gemini内に入口がなければ、利用中のGemini Notebook側で作成してください。Gemini側ではWeb検索なども使えるため、資料だけを根拠にする指示と回答の確認が必要です。

Geminiでチャットを自動保存したり、ノートブック内の過去のチャットを回答に利用したりするには、「アクティビティの保存」をオンにする必要があります。Gemini Notebookの共有ノートブックはGemini側のサイドバーには表示されないため、共有リンクからGemini Notebookで開いてください。

公式情報：Gemini：ノートブックの作成と指示 ／ Gemini Notebook：プランと上限

Microsoft 365 Copilot：エージェント

  1. 会社・学校のアカウントで「Agents & Skills（エージェントとスキル）／新しいエージェント」を開く。
  2. 手動設定なら「Skip to configure」を選び、名前・説明・指示を入れる。
  3. Knowledge（ナレッジ）に業務資料を追加し、Try it（テスト）で質問する。

名前・指示・知識を設定して使う専用アシスタントです。作成・利用には、組織のライセンスと管理者設定の確認が必要です。

公式情報：Microsoft 365：エージェントの作成 ／ Microsoft 365：エージェントへのスキル追加 ／ Microsoft 365：エージェントの利用条件

回答範囲に注意：「Only use specified sources」は登録ソースを優先する設定で、一般知識を完全に遮断する機能ではありません。厳密な制御にはCopilot Studioの設定も検討します。

公式情報：Microsoft 365：知識と回答範囲の設定

Copilot（個人）：ノートブックが使える場合

ノートブックに業務資料を追加し、「… → Instructions（指示）」に共通の設定を保存します。個人向けはMicrosoft 365 Personal／Family／Premium／Proで提供が案内されています。会社向けエージェントとは入口と利用条件が異なります。

公式情報：Copilot：ノートブックへの指示

共有するとき

共有メニューから相手や範囲を選びます。会話だけでなく、指示や資料を相手が閲覧できるかも確認してください。

公式情報：Claude：プロジェクト ／ Copilot：ノートブックへの指示

以前掲載していた手順とスクリーンショットです。画面を見ながら操作したい場合はこちらを参照してください。現在の名称・利用条件は上の最新ガイドに記載しています。GPT／Gemの移行については「スキル」タブをご覧ください。無料・有料の条件は各サービスの公式情報を優先してください。

ChatGPT

プロジェクトで作る

  1. 左のサイドバーの「プロジェクト」の横にある「＋」（プロジェクトを新規作成）を押す
  2. プロジェクト名を入力して「プロジェクトを作成する」
  3. プロジェクト画面の右上の「…」→「プロジェクト設定」を開く
  4. 「指示」の欄に設定のプロンプトを貼って「保存する」
  5. 「情報源」タブ →「ソースを追加」から資料を入れる（アップロード、テキスト入力、Googleドライブなど）
  6. プロジェクトの入力欄（「〇〇内の新しいチャット」）から質問する

GPT で作る（すでに使っている人向け）

  1. 「GPT」→「作成」を開き、「構成」タブを選ぶ
  2. 名前・説明・指示を入力する
  3. 「知識」の「ファイルをアップロードする」で資料を入れる
  4. 右上の「作成する」で保存

チャットで資料を渡す（保存しない場合）

Claude

  1. 左のサイドバーの「プロジェクト」→ 右上の「新規プロジェクト」
  2. 「何に取り組んでいますか？」に名前を入れて「プロジェクトを作成」
  3. プロジェクト画面の「指示」の鉛筆マークから、設定のプロンプトを書いて「指示を保存」
  4. 「コンテキスト」の「＋」から資料を追加する（ファイル、テキスト、Googleドライブなど）
  5. 上の入力欄から質問する

Gemini（Gem）

  1. 左のサイドバーを開いて「Gem」→「新しいGem」
  2. 名前・説明・カスタム指示（設定のプロンプト）を入力する
  3. 「知識」の「＋」から資料を追加する（ファイル、Googleドライブ、Gemini Notebook など）
  4. 右の「プレビュー」で試して、「保存」

Gemini Notebook（旧NotebookLM）

  1. notebook.google.com を開いて「新規作成」
  2. 「ソースを追加」から資料を入れる（ファイル、Webサイト、ドライブ、コピーしたテキストなど）
  3. 「ソース」タブで、使う資料にチェックが入っているか確認する
  4. 「チャット」タブで質問する

Microsoft 365 Copilot（会社のアカウント）

  1. 左の欄の「エージェント」→「新しいエージェント」（スマホでは作れません）
  2. 「自分だけのエージェントを構築する」画面の右上の「スキップ」を押す（会話で作る方法もありますが、スキップすると入力欄に直接書けます）
  3. 「構成」タブで、名前・説明・指示（設定のプロンプト）を入力する
  4. 「ナレッジ」で資料を追加する（添付ファイル、クラウドファイル、Web検索など）
  5. 右上のボタンから作成（保存）する。作ったエージェントは、開いて右上の「…」→「エージェントを共有」から同僚に共有できます

Copilot（個人向け）

  1. 左の欄の「ノートブック」→「新しいノートブック」
  2. ノートブック名を入れて「次へ」
  3. 「参照」に資料を追加して「作成」（アップロード、リンク、OneDrive）
  4. ノートブック画面の右上の「…」→「手順」に設定のプロンプトを書いて「保存」
  5. ノートブックの入力欄から質問する
