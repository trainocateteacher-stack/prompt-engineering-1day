各社の呼び方と、スキルとの使い分け

桜風町の観光案内は、次の2通りで作れます。どちらも「観光大使として答える指示」と「町の資料」を保存します。

作り方準備するもの使うときの操作
専用の場所で質問する「桜風町」というプロジェクト／ノートブックに、指示と資料を入れるその場所を開いて質問する
普段のチャットから呼び出す「桜風町の観光案内」というスキルなどに、指示と資料を入れるチャットで作ったものを選び、「名産品は？」と質問する

共通の設定

  1. 名前を「桜風町の観光大使」にする。
  2. 下の指示を保存する。
  3. 演習4の「桜風町の特徴」を知識・ソース・参照資料として追加する。登録欄がなければ指示の末尾に資料を貼る。
  4. 保存先の中で新しいチャットを開くか、作ったスキル／プラグイン／エージェントを明示して質問する。
あなたは桜風町の観光大使です。
観光客の質問に、明るく丁寧に答えてください。
提供された「桜風町の特徴」に書かれている情報だけを根拠にしてください。
資料にないことは推測せず、「申し訳ありませんが、その情報はお答えできません」と答えてください。

資料を渡しただけで、必ず検索方式（RAG）になるとは限りません。「資料に基づく回答」と「資料外の質問への対応」を観察します。

ChatGPT：プロジェクト／プラグイン

プロジェクトで試す

  1. プロジェクトを作り、名前を付ける。
  2. プロジェクトの指示に共通の設定を入れ、ソースに町の資料を追加する。
  3. そのプロジェクト内で新しいチャットを始め、質問する。

公式情報：ChatGPT：プロジェクト

回答手順を再利用するならスキル／プラグイン

ChatGPTはGPTからプラグインへの移行を案内しています。スキルが仕事の手順を持ち、プラグインがスキルやアプリをまとめます。移行の対象・時期は利用中のワークスペースの案内を確認してください。

  1. 作成機能がある場合、入力欄の「@」からPlugin Creatorを選ぶ。
  2. 「桜風町の観光案内プラグインを作成。町の資料だけを根拠にし、資料にない質問には答えない」と伝え、共通の指示と資料を渡す。
  3. 作成後、指示・参照資料を確認し、新しいチャットで「@」から選んで試す。

単独スキルの入口はChatGPTデスクトップアプリの「Skills」。Webでの利用・配布はプラグインを使う方法で確認できます。作成・共有の可否は提供状況と権限によります。

公式情報：ChatGPT：プラグインの作成 ／ ChatGPT：GPTからプラグインへの移行 ／ ChatGPT：スキルの作成と利用

Claude：プロジェクトとスキルを併用

  1. プロジェクトを作り、プロジェクトの指示に共通の設定を入れる。
  2. プロジェクトの知識に町の資料を追加し、その中で質問する。

プロジェクトは町の資料と会話をまとめる場所。スキルは必要なときに適用する手順です。別の仕事でも同じ「資料を確認して答える手順」を使う場合に向きます。

スキルはCustomize → Skills → ＋ → Create skill → Upload a skillからスキルフォルダのZIPを追加し、有効にします。コード実行・ファイル作成が必要です。質問時にスキル名を指定すると、適用を確認しやすくなります。

公式情報：Claude：プロジェクト ／ Claude：スキルとは ／ Claude：スキルの追加・利用・共有

Gemini：Gemからスキルへ

移行予定：18歳以上の個人アカウントでは、2026年11月17日にGemがスキルへ移行し、Gem自体は読み取り専用になります（使用・編集・新規作成不可）。12月17日にGemは削除。仕事用は2027年3月、教育機関は6月が予定されています。11月4日現在は、移行前のGemが見える場合もあります。

公式情報：Gemini：Gemからスキルへの移行

  1. Geminiの「カスタマイズ → スキル → 作成 → 手動で作成」を開く。
  2. 名前・説明・共通の指示を入れ、「追加」から町の資料を登録する。
  3. 作成後、チャットでスキルを指定して質問する。公式案内では「/」から呼び出し（「@」へ変更予定）。表示中の候補から選ぶ。

名前の例は sakurakaze-guide。説明には「桜風町の観光について質問されたときに使う」と書きます。自動で選ばれることもありますが、演習では明示して試します。資料は作成時の追加欄、またはSKILL.mdと参照資料を含むフォルダ／ZIPで登録できます。対応形式はアップロード画面と公式ヘルプで確認してください。

公式情報：Gemini：スキルの作成・管理（パソコン） ／ Gemini：Gemからスキルへの移行

Gemini Notebook：資料を中心に試す

  1. Geminiの「ノートブック → 新しいノートブック」で名前を付ける。
  2. 「ソースを追加」から町の資料を入れる。
  3. ノートブックの設定に共通の指示を入れ、ノートブック内で質問する。

資料・カスタム指示・会話をまとめて扱う方法です。Geminiとの連携は順次提供。Gemini内に入口がなければ、利用中のGemini Notebook側で作成してください。Gemini側ではWeb検索なども使えるため、資料だけを根拠にする指示と回答の確認が必要です。

公式情報：Gemini：ノートブックの作成と指示 ／ Gemini Notebook：プランと上限

Microsoft 365 Copilot：エージェントに知識とスキルを設定

  1. 会社・学校のアカウントで「Agents & Skills（エージェントとスキル）／新しいエージェント」を開く。
  2. 手動設定なら「Skip to configure」を選び、名前・説明・指示を入れる。
  3. Knowledge（ナレッジ）に町の資料を追加し、Try it（テスト）で質問する。

まず指示と知識だけで実施できます。回答手順を別に持たせる場合は、Agent Builderにスキル作成を依頼するか、SKILL.mdを含むZIPを追加します。スキルはエージェントに組み込む部品です。

公式情報：Microsoft 365：エージェントの作成 ／ Microsoft 365：エージェントへのスキル追加 ／ Microsoft 365：エージェントの利用条件

回答範囲に注意：「Only use specified sources」は登録ソースを優先する設定で、一般知識を完全に遮断する機能ではありません。厳密な制御にはCopilot Studioの設定も検討します。

公式情報：Microsoft 365：知識と回答範囲の設定

Copilot（個人）：ノートブックが使える場合

ノートブックに町の資料を追加し、「… → Instructions（指示）」に共通の設定を保存します。個人向けはMicrosoft 365 Personal／Family／Premium／Proで提供が案内されています。会社向けエージェントとは入口と利用条件が異なります。

公式情報：Copilot：ノートブックへの指示

共有時は指示や資料も相手に見える範囲を確認してください。ChatGPTの移行後プラグインは共有先を再設定。Claudeのプロジェクト／スキルの組織内共有はTeam／Enterpriseの権限に従います。

保存機能が表示されない場合も、通常のチャットに共通の指示と町の資料をまとめて貼れば、資料に基づく回答の演習はできます。
