短い練習　旅行の条件を伝える

P40～45／必修・15分

目的・条件・出力形式と、要確認事項を伝える。
  1. 課題から必要な条件を選び、自分で指示を書く（3分）。
  2. 1回実行し、条件の抜けと、確定情報のように書かれた概算を確認する（5分）。
  3. 不足を1か所直して追加指示を送る（3分）。
  4. 確認したことを共有する（4分）。

指示に含める条件を選び、最初のプロンプトを自分で書いてください。
実在店の最新営業時間や正確な運賃の検索は、この課題の必須ではありません。
候補地・時間・概算費用・要確認事項が分かる形で出力させます。

演習1　資料から訂正メールを作る

P64～65／必修・25分

資料の事実を保ち、確認して追加指示で直す。
  1. 課題と資料を読む（3分）。
  2. 指示を書き、資料と一緒に1回実行する（8分）。
  3. チェックリストで照合し、不足を1か所直す（6分）。
  4. 確認結果を共有し、自分の指示を保存する（8分）。

課題

資料に基づき、誤りの報告・謝罪と、修正版の確認を依頼するメールを作ってください。
先に自分で指示を書いて、AIへ資料と一緒に渡します。
件名と本文を分け、本文はおおむね300字以内。2点の訂正と確認期限を含めます。
資料にない事実・ミスの原因・再発防止策は作らないでください。
出力を資料と照合し、不足があれば追加指示で1か所直します。
最後に、自分が使った指示をメモへ保存してください。

演習3　アンケートを基準と例で分類する

P79～81／必修・20分

分類定義を使い、複数の話題と判定保留を扱う。
  1. ルールと例を読む（3分）。
  2. 自分で指示を書くか、下のプロンプトを使って1回実行する（7分）。
  3. 6件のID・元回答・分類・根拠を照合し、必要なら1回直す（6分）。
  4. 保留や複数分類にした理由を共有する（4分）。

課題

架空の回答6件を分類してください。Excel添付は不要です。下の本文を貼り付けて使います。

実行用プロンプト

次のルールで回答6件を分類してください。IDと元回答を省略・変更せず、1件を1行にしてください。

【架空の研修アンケート：分類ルール】
内容：説明・教材・演習の内容への意見。
操作：ログイン・画面・接続など、ツール操作や環境への意見。
時間：進行速度・演習時間・休憩への意見。
判定保留：対象が読み取れない、または上の3分類に当てはまらない。
複数の話題があれば複数分類を可とする。好評・不評は分類軸にしない。
対象が不明な部分は推測せず、分かる分類と判定保留を併記してよい。
出力列：ID｜元回答｜分類｜根拠（元回答から短く引用）

【分類例：下の6件とは別の回答】
E01｜説明の用語が難しかった。｜内容｜「説明の用語」
E02｜ボタンの場所が分からず、演習時間も足りなかった。｜操作・時間｜「ボタンの場所」「演習時間も足りなかった」
E03｜よかったです。｜判定保留｜「よかった」だけでは対象が不明

【分類する回答】
A01｜具体例が多く、説明が分かりやすかった。
A02｜ログイン画面から先へ進めなかった。
A03｜演習時間をあと5分増やしてほしい。
A04｜教材は分かりやすいが、休憩が短かった。
A05｜少し気になりました。
A06｜画面が固まり、説明の例も分かりにくかった。
指示・回答の確認例講師の合図のあとで開きます

演習4　資料に基づく桜風町FAQ

P100～105／必修・40分（休憩は別枠）

資料にある・未記載・範囲外を区別し、根拠と計算を確認する。
  1. 資料と課題を読む（5分）。
  2. 自分で案内係の指示を作り、資料と4問をまとめて送る（15分）。
  3. 回答と出典・計算を照合し、指示を1か所直す（10分）。
  4. 確認結果を共有し、指示をメモへ保存する（10分）。

課題

通常チャットで観光案内係を試します。回答に資料IDを付け、未記載・未定・対象範囲外の答え方を決めてください。アプリ開発や専用機能への登録は不要です。

入力資料

【架空の観光資料：桜風町】
S1：桜風町は、東北地方の山々に囲まれた架空の町。
S2：名産品は桜風せんべい。桜の葉を使い、チョコレート味とチーズ味がある。
S3：桜の迷路公園の開園時間は9:00～17:00。入園料は大人500円、小学生200円、未就学児無料。
S4：桜風陶器の体験教室は1人2,000円。所要時間60分。事前予約が必要。予約方法は未記載。
S5：桜風変装パレードは毎年4月開催。2027年の開催日は未定。
S6：桜風渓谷では春に夜桜のライトアップを行う。実施日・点灯時間は未記載。
この資料には人口・宿泊施設・交通手段の記載はない。

試す質問

Q1 桜の迷路公園の開園時間と、大人2人・小学生1人の入園料合計は？
Q2 桜風町の人口は何人？
Q3 東京のおすすめ観光地は？
Q4 2027年の桜風変装パレードは何月何日？

確認観点

Q1：計算とS3／Q2：人口は未記載／Q3：範囲外／Q4：4月開催・日付未定。資料の内容と合っているか確認してください。
指示・回答の確認例講師の合図のあとで開きます
