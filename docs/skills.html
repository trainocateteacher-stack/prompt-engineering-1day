スキル

同じ指示を毎回入力せず、必要なときに呼び出す機能。2026年11月4日の公式情報に基づく説明です。

スキルと各社の呼び方

スキルは、繰り返し使う指示や手順を保存したものです。例えば「文書を読んで、要点・確認事項・次の行動の順にまとめる」といった手順を保存できます。

作り方準備するもの使うときの操作
専用の場所で質問する「対象業務」というプロジェクト／ノートブックに、指示と資料を入れるその場所を開いて質問する
普段のチャットから呼び出す「文書要約」というスキルなどに、指示と資料を入れるチャットで作ったものを選び、「要点をまとめて」と質問する

同じ列は、資料を使う場面で近い使い方ができる機能です。各社で機能が完全に同じという意味ではありません。

プラグインとスキルは、何が違う？

スキルは「何をどう答えるかの指示と資料」。プラグインは「そのスキルをまとめて追加・共有するセット」です。資料を使う場面では、1つのスキルだけを入れたプラグインでも構いません。

対象業務の例入っているもの
スキル「文書要約」「資料を読んで答える」「資料になければ答えない」という指示と、参照資料。
プラグイン「文書要約セット」上のスキルを入れたもの。必要なら複数のスキルや外部サービスへの接続もまとめられる。

受講者がすること：ChatGPTでプラグインとして作った場合は、そのプラグインを選んで質問します。中にあるスキルが回答の手順を決めます。対象業務の利用時は、外部アプリとの接続は不要です。

公式情報：ChatGPT：プラグインの作成

間違えやすい点：「プロジェクト」「Gem」「エージェント」「スキル」が、すべて同じ機能の別名というわけではありません。特にChatGPTのプラグインとMicrosoft 365のエージェントは、中にスキルを持てます。

まず使うなら：ChatGPT／Claudeはプロジェクト、Geminiはスキル（表示がなければ移行前のGem）、Microsoft 365はエージェントなど、お使いの画面にある方法を1つ選んでください。複数の機能を一度に覚える必要はありません。

公式情報：ChatGPT：プロジェクト ／ ChatGPT：スキルの作成と利用 ／ Claude：プロジェクト ／ Gemini：ノートブックの作成と指示

AIが自動で使うこともある

名前と説明をもとに、AIが質問に合うスキルを選ぶことがあります。必ず選ばれるとは限らないため、動きを確認するときはスキル名を指定します。

例：説明に「文書の要約を依頼されたときに使う」と書く → 「この資料を要約して」と依頼する → AIが該当するスキルを選び、保存した手順でまとめる。

公式情報：ChatGPT：スキルの作成と利用 ／ Claude：スキルとは ／ Gemini：Gemからスキルへの移行

ChatGPTのスキル／プラグイン

回答手順を再利用するならスキル／プラグイン

ChatGPTはGPTからプラグインへの移行を案内しています。スキルが仕事の手順を持ち、プラグインがスキルやアプリをまとめます。移行の対象・時期は利用中のワークスペースの案内を確認してください。

  1. 作成機能がある場合、入力欄の「@」からPlugin Creatorを選ぶ。
  2. 「文書要約プラグインを作成。業務資料だけを根拠にし、資料にない質問には答えない」と伝え、共通の指示と資料を渡す。
  3. 作成後、指示・参照資料を確認し、新しいチャットで「@」から選んで試す。

単独スキルの入口はChatGPTデスクトップアプリの「Skills」。Webでの利用・配布はプラグインを使う方法で確認できます。作成・共有の可否は提供状況と権限によります。

公式情報：ChatGPT：プラグインの作成 ／ ChatGPT：GPTからプラグインへの移行 ／ ChatGPT：スキルの作成と利用

Claudeのスキル

Customize → Skills → ＋ → Create skill → Upload a skillからZIPを追加し、有効にします。コード実行・ファイル作成が必要です。

公式情報：Claude：スキルとは ／ Claude：スキルの追加・利用・共有

Gemini：Gemからスキルへ

移行予定：18歳以上の個人アカウントでは、2026年11月17日にGemがスキルへ移行し、Gem自体は読み取り専用になります（使用・編集・新規作成不可）。12月17日にGemは削除。仕事用は2027年3月、教育機関は6月が予定されています。11月4日現在は、移行前のGemが見える場合もあります。

公式情報：Gemini：Gemからスキルへの移行

  1. Geminiの「カスタマイズ → スキル → 作成 → 手動で作成」を開く。
  2. 名前・説明・共通の指示を入れ、「追加」から業務資料を登録する。
  3. 作成後、チャットでスキルを指定して質問する。公式案内では「/」から呼び出し（「@」へ変更予定）。表示中の候補から選ぶ。

名前の例は document-summary。説明には「対象業務の観光について質問されたときに使う」と書きます。自動で選ばれることもありますが、利用時は明示して試します。資料は作成時の追加欄、またはSKILL.mdと参照資料を含むフォルダ／ZIPで登録できます。対応形式はアップロード画面と公式ヘルプで確認してください。

公式情報：Gemini：スキルの作成・管理（パソコン） ／ Gemini：Gemからスキルへの移行

Microsoft 365 Copilotのスキル

エージェントに追加する部品です。Agent Builderに回答手順の作成を依頼するか、SKILL.mdを含むZIPを追加します。対象ライセンスまたは従量課金設定が必要です。

公式情報：Microsoft 365：エージェントへのスキル追加 ／ Microsoft 365：エージェントの利用条件
