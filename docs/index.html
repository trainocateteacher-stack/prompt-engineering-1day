1日で学ぶプロンプトエンジニアリング　受講者用ページ

講義で使うプロンプトや演習を、このページからコピーして使えます。

困ったとき（音声トラブル・接続障害など）

技術サポート窓口　メール：OnlineLive_Support@trainocate.co.jp　電話：03-3347-9404

Zoomのチャットでは、すぐに対応できないことがあります。急ぎのときはメール・電話へ。　連絡先の詳細

受講案内講習時間・音声トラブル・My Trainocate Portal・連絡先などサービス別ガイドChatGPT・Claude・Gemini・Copilot で、設定を保存する方法と資料を渡す方法（無料・有料）逆引きチートシート「何をしたいか」から、使う技・書き方・テンプレートを引ける一覧プロンプト集講義中に使うプロンプト。「No.○○」を見つけて［コピー］演習演習の課題とプロンプト。解答は講師の合図のあとで開きます要点まとめ章ごとの要点を1つのテキストに。一括コピー・保存できます参考サイト復習や、もっと知りたいときのリンク集

使い方

  1. 講師が「プロンプト集の No.○○」と言ったら、その番号の［コピー］を押します
  2. お使いのAIチャット（ChatGPT／Copilot／Gemini／Claude、社内ツールなど）に貼り付けて実行します
  3. 演習の解答例は、講師の合図のあとで開けるようになります（ページを開いたままでOK）

研修中のルール

  • 個人情報・機密情報は、AIに入力しない（本日は一律で）
  • AIの出力を、そのまま外部へ大々的に発信しない
  • 実務では、会社が契約しているサービスと社内ルールの範囲で判断する
講師の画面と結果が違っても問題ありません。AIの答えは毎回少しずつ変わります。
