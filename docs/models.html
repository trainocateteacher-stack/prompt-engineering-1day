数字を読むときのポイント

  • 総合指数：Artificial Analysis Intelligence Index v5.0。知識業務・コード・科学・一般分野をまとめた指数です。50は「正答率50％」ではありません。主に英語の評価で、日本語業務の成績を直接保証しません。
  • HLE-Diamond：高度な知識と推論を問う個別テストの成績。総合指数とは別の尺度です。
  • 待ち時間と出力速度：回答開始までは、入力処理や考える時間も含みます。出力速度は文章が流れる速さで、読み終わるまでの総時間とは別です。tokenは文字数と同じ単位ではありません。
  • 図から分かること：SolのLowからHighでは得点が上がり、回答開始までの待ち時間も増えています。一方、出力速度はHighのほうが高く、「速度」の定義で見え方が変わります。
  • 全モデルの比較：同じ版の指数を並べていますが、各社の推論設定・フォールバック条件は同一ではありません。得点と速度は別のテストで測られています。点を結んだ普遍的なトレードオフ曲線とは扱いません。
  • 掲載範囲：モデル一覧に関連する6条件を抜粋。Copilot Chatは搭載モデル・処理経路・参照資料が変わるため、サービス全体へ単一の点数を付けていません。未掲載モデルの成績を推測で補っていません。
  • 更新：閲覧時点の公開値を転記しています。API速度は接続先・混雑・入力長で変動し、出典の表示値も更新されます。小数点差を絶対的な優劣とは見なさず、実際の仕事でも試してください。

表の見方

  • 通常チャットと作業用機能を区別：ChatGPTのChat、Work、Codexでは利用モデルが異なります。GPT-6.1があるから、通常チャットでも同じモデルとは限りません。
  • Microsoft 365の「追加料金なし」：対象契約が前提です。個人向けMicrosoft Copilotとも別のサービス条件です。
  • モデル名と利用枠は別：同じモデル名でも、無料・有料で使える回数や機能が異なる場合があります。
  • 比較の範囲：一般向けのチャットサービスが中心です。APIだけで利用できるモデル、限定プレビュー、各社の全モデルを網羅した一覧ではありません。相対的な性能順位を示すものでもありません。
  • 確認できた情報：ChatGPTのChat欄は、公式更新情報の2026年8月6日掲載内容を確認したものです。Work／Codex欄は現行のモデル案内を参照しています。画面の表示が異なる場合は、利用中のアカウントの表示と公式案内を優先してください。
